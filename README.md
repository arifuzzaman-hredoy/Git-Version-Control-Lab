# Project 07 — Git Version Control

A practical, hands-on Git version control laboratory designed to build strong version control skills for a Junior DevOps Engineer.

## Project Overview

This project focuses on understanding and using Git to track changes, manage source code, maintain project history, and recover from common version control mistakes.

The goal is to develop practical Git skills through real-world exercises rather than memorizing commands.

## Learning Objectives

- Understand version control and Git fundamentals.
- Configure Git identity and environment.
- Create and manage local repositories.
- Track files and changes.
- Understand the staging area and working directory.
- Create meaningful commits.
- Inspect repository history and differences.
- Restore files and recover from mistakes.
- Work with remote repositories.
- Understand Git tags and releases.
- Follow clean and maintainable Git workflows.
